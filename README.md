# Speed Test

Консольный скрипт на Python для замера скорости скачивания по HTTP.

## Что делает

1. Принимает URL в качестве аргумента командной строки.
2. Делает **10 последовательных** GET-запросов и ждёт полного ответа на каждый.
3. Считает:
   - время каждого запроса,
   - среднее время запроса,
   - общий объём скачанных данных,
   - скорость скачивания.
4. Печатает результат в консоль.

## Требования

- Python 3.8+
- библиотека [`requests`](https://requests.readthedocs.io/)

## Установка

```bash
git clone <repo-url>
cd <repo-dir>
pip install requests
```

## Запуск

```bash
python speed_test.py <URL>
```

Пример с публичным тестовым файлом (100 МБ):

```bash
python speed_test.py https://speed.cloudflare.com/__down?bytes=104857600
```

## Пример вывода

```

  [ 1/10]   1.234 с  |     104857600 байт
  [ 2/10]   1.210 с  |     104857600 байт
  ...

РЕЗУЛЬТАТЫ

```

## Единицы измерения

| Величина              | Единица                |
|-----------------------|------------------------|
| Время                 | секунды (с)            |
| Размер данных         | байты и МБ (1 МБ = 2²⁰ байт) |
| Скорость скачивания   | **Мбит/с** (мегабит в секунду, 1 Мбит = 10⁶ бит) |

Скорость считается по формуле:

```
speed = (total_bytes * 8) / (total_time * 1_000_000)
```

## Как это работает

- Используется `requests.get(url)` без `stream=True`, поэтому запрос считается завершённым только после получения **всего** тела ответа — как и требуется в ТЗ.
- Для замера времени используется `time.perf_counter()` — он даёт более точные значения на коротких интервалах, чем `time.time()`.
- На каждый запрос выставлен `timeout=60` секунд, чтобы скрипт не висел бесконечно при проблемах с сетью.
